# Bisaat (بساط) 🧶

A custom web-based store interface for Yemeni hand-woven and tufted rugs, designed for personalized carpet and wall hanging specifications.

## ✨ Features
- **Custom Order Interface:** Allows users to specify custom dimensions, patterns, and designs for handmade rugs.
- **Visual Catalog:** Showcases custom patterns, artwork identity assets, and product categories.
- **Responsive Design:** Clean and modern layout optimized for web browsing.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, custom styling)
- JavaScript

## 📂 Project Structure
- `BisaatStore.html` - Main store interface
- `BisaatStoreStyle.css` - Custom styling and layout
- `Identity/` - Brand logos, icons, and color identity assets
- `pic/` - Product photos, patterns, and design references
